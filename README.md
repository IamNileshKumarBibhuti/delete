# Neon Pantry AI

A futuristic recipe experience with neon-glass UI, AI recipe guidance, ingredient price comparison, and tab-based navigation. The interface is designed to highlight quick search, featured recipes, ingredient management, pricing intelligence, and an interactive FAQ.

## Features

- Tab-based navigation with smooth transitions across Home, Recipes, Ingredients, Pricing, Services, and FAQ.
- Advanced recipe search, filter, and sorting placeholders for difficulty and cook time.
- Save, share, and favorite actions with animated feedback.
- Smart ingredient entry with suggested items and price estimation.
- Store comparison links for Zepto, Blinkit, Instamart, and BigBasket.
- Pricing intelligence panel with cost summary and recommended store.

## Getting started

Open `index.html` in a browser or serve the folder with a static server.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
